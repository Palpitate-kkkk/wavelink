# 捕获后的自适应统计接收：缺失时隙、延迟校准与统计摄入门限

v0.19 把有限时隙捕获前端接到原延迟复核 LMMSE 接收机。重点是明确不完整输入下的因果行为，而不是假定每个通过捕获阈值的包都可靠。新增 `SlotTrackedLMMSE`，旧捕获代码和旧统计接收器保持冻结。

## 两个时钟与当前帧的处理

物理时隙计数每个时隙都前进，包含没有接收缓冲区、捕获被拒绝或统计门限不通过的时隙。子接收机的观测计数，只在校准完成后实际摄入一个被接纳的导频帧时前进。

- 没有输入或捕获拒绝时，返回缺失结果，物理时间前进；不补零、不复用上一帧、不改变统计窗口，也不执行拟合。
- 捕获接受时，先用当前已有模型估计本包。之后才摄入允许使用的导频；新模型最早供下一物理时隙使用。外部误码评分只使用已经返回的估计，不参与更新。
- 不通过统计门限的包仍正常解调，输出误码照常计分；它只是不能进入后续的统计学习。
- 统计窗口、监测间隔、冷却与复核等待都沿用原子接收机的**被接纳观测时钟**。例如 64 个观测的复核等待，不代表 64 个物理时隙。缺失期间计划仍可 pending，但不执行；恢复后继续累计观测。
- 最后一个时隙只解调，不摄入、不构造无用校准模型、不执行复核；未执行计划保留 pending，接收器随后关闭。

单元测试隔离调度状态机，验证安排复核后缺失 100 个时隙不会拟合，再接纳 64 个观测才执行一次复核。这个策略是明确且可复现的时钟约定，不代表最优时效策略；长缺失会保留物理年龄较老的数据和模型。

## 启动与导频门限

每段链路先发送 64 个初始校准时隙，再发送 320 个计分时隙。实际校准使用前 64 个被接纳的导频帧；不足时先用每包 L=17 的时域 LS 解调，凑齐后构造原 LMMSE，下一时隙才使用。没有延长发送预算，也没有补发训练。若校准延后到计分段，当前计分包仍先按已有模型/LS 解调，再允许其导频供未来学习；这些启动帧全部计分，不能只报告模型准备好后的结果。

新增统计门限只使用观测导频。设 `Z=Yp/Xp`，固定 28 导频、长度 17 的部分 DFT 设计矩阵为 F，计算：

```
P = F pinv(F)
r = ||Z - Z P^T||²_F / ||Z||²_F
```

比例在 20 个符号上合并，零能量时设为 1。r 不超过门限才允许统计摄入。门限不使用真实噪声、真实 PDP、变化点、实际捕获是否正确或误码。它仅检验观测与既定空间模型的一致性，不保证正确同步；低信噪比、残余 CFO 和不稳定定时仍可能造成偏置。

原接收器创新阈值 2、统计阈值 0.75、64 观测拟合窗口、16 观测监测窗口、8 观测检查间隔、32 观测冷却、64 观测延迟复核全部冻结。捕获阈值继续使用上一版开发锁定的 0.2。

## 对照与物理输入

同一段潜在发送数据、抽头、噪声和到达位置用于以下对照：

1. **LS**：捕获后每包 LS17/ZF/QPSK，不学习历史统计。
2. **capture_adaptive**：仅按捕获接受结果摄入，使用原延迟复核 LMMSE。
3. **gate_0.25**：再用导频门限过滤统计，使用相同自适应接收器。
4. **frozen_0.25**：相同门限和启动数据，只冻结启动得到的 LMMSE，不再拟合；用于区分启动保护与继续自适应的作用。
5. **oracle_adaptive**：知道真实边界与 CFO 的参考，仍只从导频学习统计，承受同样的接收缓冲区缺失；没有真实 PDP、噪声或瞬时信道先验。它不是最优 BER 下界。

所有真实捕获分支的包接受/拒绝相同；统计门限不额外抹除数据。非安全捕获只由评分器在事后标记，定义沿用 [捕获报告](acquisition.md) 的 CP 安全区间和 0.05 子载波频偏容差。该标记是充分安全条件的违反，不等于每个此类包都实际误码；记录其统计摄入数量，不能把所有标记都断言为有害污染。

采样率 1 MHz、FFT=64、CP=16、28 导频/24 数据子载波、QPSK，每包 20 个计分符号、960 bit，沿用 224 点固定包头与 1 个 warmup。每包的信道帧内静态、帧间独立，不相关整数抽头，不逐帧归一化。捕获位置逐包在 0..63 点内变化，接收时隙长度 1,984 点。

五个工作负载为：

| 场景 | 输入条件 |
|---|---|
| stationary | 始终 initial PDP、CFO=1.2 |
| weak_drift | 计分时隙 80 起由 initial 变为 weak15，其余 CFO=1.2 |
| gap32 | 同样的 PDP 变化；计分时隙 96..127 的接收缓冲区不可用 |
| alias64 | 同样的 PDP 变化；计分时隙 96..159 的 CFO 改为 5.2，超出候选范围 |
| dirty_calibration | 初始校准时隙 16..47 的 CFO 为 5.2；计分段恢复 CFO=1.2，并在时隙 80 发生上述 PDP 变化 |

`gap32` 是接收输入丢失，不是 TX 静默或把信道改成零。包仍发送，960 bit 仍属于提供数据，所有参考都没有这 32 个时隙的接收数据。真实边界/CFO 参考也不能绕过缺失缓冲区。

随机包头提前量、残余 CFO 和被选择的观测会改变接收器看到的有效统计。即使安全 FFT 窗口也可能把抽头整体平移；旧统计模型不因此自动成为无偏或匹配的真实 PDP 模型。当前链路不具有完美同步对角模型的全部假设，故没有套用原无 ICI 的条件 NMSE/BER 理论检查。

## 开发选择、独立测试与复跑核对

开发使用 281001..281004 四个新 episode 种子，测试使用 291001..291016 十六个新种子，两个 SNR（6、18 dB）和五种场景。随机包种子从 episode/校准或测试段/时隙的独立整数区块派生，与前序实验根种子隔离。每个单元有 16 段独立测试链路；五种场景共享潜在流，不能把场景数当作额外独立重复。

导频门限候选为 0.15/0.25/0.35。开发要求每个场景/SNR 的完整计分段平均损失不超过无门限自适应的 1.05 倍；合格候选中取等权单元平均损失最小者，同值取较大门限；全部失败则保留失败并取最大门限。

| 门限 | 最坏开发单元损失比 | 开发单元等权平均损失 | 合格 |
|---:|---:|---:|---|
| 0.15 | 1.000592 | 0.205608 | 是 |
| 0.25 | 1.000868 | 0.205294 | 是 |
| 0.35 | 1.000000 | 0.205431 | 是 |

因此锁定 **0.25**，开发结果、配置和源码哈希在测试开始前保存为 [selection.json](../reports/captured_tracking/selection.json)。测试后没有修改收发参数。补全继承协议的哈希检查后，用相同参数独立复跑；所有开发及测试 CSV 与首次运行逐字节一致，再归档包含完整协议校验的版本。这个复跑不是新的独立随机重复。

## 完整计分段结果

损失仍定义为 `(被接受包的错误比特 + 缺失包的全部比特) / 提供比特`。它不是 BER；接受包 BER 单独保存在汇总文件，不能用它代替丢包后的表现。所有启动延迟、外部缺失、捕获漏检和错误输出都计入完整 320 时隙窗口。另保留最后 96 时隙的 late 窗口，它与完整窗口重叠，不能当作独立结果。

### 摄入、启动与物理历史跨度

alias64、18 dB 中，每段链路被摄入的非安全捕获样本均值从 72.0625 降到 8.125；门限限制了错误输入继续进入统计窗口，但超范围包的输出仍被接受并计实际误码，没有因为门限而消失。已通过前端且不符合保守安全判据的正常包也可能留下，故不声称门限识别了全部错误。

dirty_calibration、18 dB 的初始统计池中，非安全样本均值从 32.5 降到 0.8125；代价是平均 bootstrap 时隙从 63 延后到 95（从零计数）。前 32 个计分时隙因而主要使用 LS，全部计分，不当作未计成本的额外校准。6 dB 时 bootstrap 也可能更晚，但本批 160 个场景链路中的所有方法最终都完成了启动。

gap32、18 dB 下，最近 64 个被接纳观测的最大物理跨度均值约为 96.06 时隙；alias64、18 dB 的门限接收器约为 128.06 时隙，而无门限方法约为 64.25。这说明统计过滤会延长数据的物理年龄，不能说“64 观测窗口”始终是“最近 64 时隙”。全部缺失窗口中都没有模型拟合事件。

### 仍未解决的失败边界

门限保护**未全面胜过简单接收器**。alias64、18 dB 的门限自适应损失 0.114746 仍高于 LS 的 0.113599 和同门限冻结的 0.113683；dirty_calibration、18 dB 也仍高于这两种参考。weak_drift、18 dB 中，无门限和门限自适应都高于冻结模型。统计摄入更干净，不保证继续更新一定有收益。

十个完整窗口单元中，门限自适应相对无门限自适应的最坏平均损失比为 1.000072（gap32、6 dB），存在轻微退化。全部单元均值在开发设定的 1.05 参考内，不构成总体非劣效检验或逐链路保证。

6 dB 的损失仍主要受捕获漏检和不稳定定时影响。例如 weak_drift 的有门限接受包 BER 约 0.122728，但全包损失为 0.307092；不能只用前者宣传可靠性。门限没有增加 CRC、整数频偏拒绝认证或失配后的可靠重新捕获，也没有解决定时平移导致的统计混合。

## 验证、成本与复现

**164 项自动测试通过。** 覆盖全接纳时与旧 Followup 逐元素一致、缺失不补零、不充分校准时的 LS 启动、门限只过滤统计、当前估计使用更新前模型、跨缺失的复核等待、最后无用更新边界、冻结参考不重拟合、未来观测不改变过去、参数与独立种子检查、开发择优和失败兜底。

保留测试包含 160 段场景链路、61,440 个发送/接收时隙（含初始校准）和 51,200 个计分时隙。剔除 gap32 的接收缓冲区缺失后，**60,416 次真实同步/零频偏栅格一致性检查通过**。缺失时隙没有被计成已执行检查。另核对计划数量守恒、所有拟合最早在下一时隙生效、最后时隙不拟合，以及门限冻结/自适应两方法的摄入掩码完全一致。

所有捕获分支的提供比特和接受比特相同，因此门限收益没有来自额外丢弃待评分数据。初始 64 个校准时隙和测试 320 个时隙固定，各方法共同承担相同发送预算；LS 参考不需要学习，但本轮同样置于该固定发送预算中，没有为它设计更短的独立协议。每包发送能量因子仍为 1.227858632，若将初始校准摊入计分段，约为 `1.227858632×384/320=1.473430359`。没有额外导频或重传；也未声称加速，门限计算、接收器特征和监测的完整耗时尚未测量。

160 段场景链路提供计分数据共 49,152,000 bit；场景共享潜在流，32 个独立根种子/SNR 分支的不同发送计分数据只有 9,830,400 bit。不能将物理帧数、方法数或重复复跑数当成独立链路数。
