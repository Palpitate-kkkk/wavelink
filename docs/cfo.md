# 已知帧边界下的频偏估计、补偿与失败边界

v0.17 开始审计真实接收误差中的一个因素：载波频偏（CFO，Carrier Frequency Offset）。原延迟复核接收机保持冻结，新增时域频偏和重复训练前端。这里帧边界仍然已知，尚未实现包检测、定时搜索或完整同步器。

## 单位、训练与可用信息

采样率 Fs=1 MHz，FFT 点数 N=64，子载波间隔 Δf=Fs/N=15,625 Hz。归一化频偏 ε=Δf_CFO/Δf；仿真乘上 `exp(j 2π ε n/N)`，补偿时取负号。四个预设值为：

| ε | 频偏 Hz | 用途 |
|---:|---:|---|
| 0 | 0 | 检查无频偏时增加估计器的代价 |
| 0.05 | 781.25 | 捕获范围内的小频偏 |
| 0.2 | 3,125 | 捕获范围内较大频偏 |
| 1.2 | 18,750 | 超出捕获范围的失败对照 |

每个信道帧前加入 144 个采样点的训练头：16 点 CP 加四个重复的 32 点块。用 64 点 FFT 的偶数频点装载单位 QPSK、乘 √2，构成周期为 32 的时域序列；训练头允许使用 DC 和普通数据栅格的保护频点，不是既有 52 激活子载波的标准化前导，也不声称实现任何现行协议。训练有效区总能量严格为 128，CP 的期望能量为 16。

数据部分保留原来的 1 个 warmup OFDM 符号和 20 个计分符号，均为 64+16 点；每个完整信道帧总计 1,824 点。整数抽头在整个训练头、warmup 和数据区内静态，最大时延不超过 16 点，训练 CP 足够。

当前模型允许路径占满 CP，故没有把数据 CP 的所有点当成干净的重复观测。前端只对训练头去除 CP 后的 128 点，累加 96 个滞后 32 点的共轭乘积：

```
P = Σ conj(r[n]) r[n+32],  n=0..95
ε_hat = angle(P) × 64 / (2π × 32)
```

相位主值只确定模 2 的频偏，主捕获范围约为 -1..1，端点不能区分。ε=1.2 会被估计到约 -0.8，剩下约 2 个子载波间隔的整数频偏。96 个乘积有重叠，不是 96 个独立观测；没有以相关强度为门槛丢弃低质量帧。

估计器只接收训练观测、滞后和 FFT 长度；训练数据在计分负载之前收到。补偿使用已知采样计数，校准段和测试段各自从零开始计数，段内频偏恒定、采样计数连续。每个分支都经过自己的前端处理全部 64 帧初始校准，没有给估计补偿分支使用理想校准数据。原创新阈值 2、统计阈值 0.75、共享冷却 32、复核等待 64 和拟合窗口 64 均保持不变。

重复结构的频偏相位估计是经典同步思路，参考 Schmidl 与 Cox 的 [Robust Frequency and Timing Synchronization for OFDM (1997)](https://doi.org/10.1109/26.650240)。这里采用四段重复头和已知边界，只实现上述相关相位估计，没有复现其完整的定时与整数频偏获取系统，也不作为算法创新。

## 公平比较、能量与统计

每段链路包含零/非零频偏的未补偿、训练估计补偿、真实频偏补偿三个分支，后者仅为评分参考。所有分支发送相同训练头并共享校准、发送比特、信道与潜在噪声，不给某个分支额外训练预算。

为了严格检查补偿代码，将频偏同时作用于干净信号和潜在圆对称复 AWGN。圆对称白噪声的分布在确定性相位旋转下不变，因此每个分支的边缘分布与“信号先频偏、后加接收机 AWGN”一致；这是配对实验采用的共同随机数方式。真实频偏补偿能逐样本恢复零频偏潜在波形，对所有校准/计分帧检查 FFT 栅格，并对完整自适应接收路径检查解调比特和更新时刻。

**不同 ε 的结果不是独立噪声重复。** 在没有主值绕回时，估计误差会共享同一个噪声相位，估计补偿后的残余波形也会一致或只差数值精度，因此捕获范围内多个 ε 的 BER 相同是这种配对设计的预期现象，不是多次独立验证。超范围/噪声绕回会破坏这种关系。

名义 Eb/N0 继续使用数据、导频和数据 CP 的原能量定义，噪声功率保持不变。计入新训练头和原 warmup 后，每计分数据比特的期望发送能量乘以：

```
(21 × 65 + 144) / (20 × 65) = 1.16076923
```

其中每个数据 OFDM 符号期望能量为 52×80/64=65。该因子约为 +0.647 dB，训练和 warmup 都消耗能量；不能把本轮结果称为零开销补偿。若要求与无训练方案固定完整发送能量比较，还需重新缩放发射功率或噪声，当前没有进行该实验。上述因子尚未摊入 64 帧初始校准；若将其摊入全部 320 个测试帧，总期望能量因子为 `1.16076923×384/320≈1.39292308`。所有比较分支均承担相同成本。

协议在测试前写入 [protocol.json](../reports/cfo/protocol.json)，不设候选、不重新调参。采用新种子 231001..231016，独立固定排列选择 16 种变化相位，两个初始 Eb/N0（6、18 dB）和两个场景（stationary、weak15），共 64 段场景链路。每段 320 个计分帧，每帧 20 个 QPSK 数据符号；post_all 为变化起点后的 224 帧，pre 为之前 32 帧。只覆盖 32 相位中的 16 种，不声称全相位审计。

每个场景/SNR 的 16 段链路用于计算 episode BER 均值及配对差 SE；四个频偏、两个场景共享潜在随机流，不额外增加独立样本数。SE 含种子与固定相位差异，每相位没有多次重复，也没有把比特或帧直接当成独立信道样本。原来的对角信道 NMSE 和无 ICI 理论 BER 公式没有强行用于剩余 CFO 分支。

| stationary | 18 dB | 0.05 | 0.098721 | 0.011555 | 0.011547 |
| stationary | 18 dB | 0.2 | 0.499588 | 0.011555 | 0.011547 |
| stationary | 18 dB | 1.2 | 0.495313 | 0.499509 | 0.011547 |
| weak15 | 6 dB | 0 | 0.128353 | 0.128530 | 0.128353 |
| weak15 | 6 dB | 0.05 | 0.175597 | 0.128530 | 0.128353 |

| weak15 | 18 dB | 0.2 | 0.499588 | 0.012490 | 0.012480 |
| weak15 | 18 dB | 1.2 | 0.494999 | 0.499682 | 0.012480 |

weak15、18 dB、ε=0.05 时，估计补偿相对未补偿的配对 BER 差为 **-0.091604 ± 0.002956（1 episode SE）**；相对零频偏参考为 +0.0000099 ± 0.0000208，有限样本中很接近，但不是严格等价或普适性能保证。ε=0.2 的未补偿接收机会同时受到 ICI、符号间相位旋转及原导频统计模型失配影响，不能把全部退化仅归因于某一种因素。

零频偏时仍有估计噪声。weak15、6 dB 的 BER 从 0.128353 变为 0.128530，差为 +0.000177 ± 0.000385（1 episode SE）；不能说加入前端对所有链路均有提升。ε=1.2 时估计补偿后的 BER 约为 0.5，当前实现没有整数频偏搜索，也没有可靠拒绝混叠结果的机制。

weak15 的整个 320 帧测试段中，ε=0.05 的频偏估计 RMSE 在 6、18 dB 分别约为 **0.03591、0.004012 个子载波间隔**；6 dB 的 5,120 帧中有 64 帧绝对估计误差大于 0.1，18 dB 则为 0 帧。这些帧来自仅 16 段链路，计数不能当作独立试验的置信区间。ε=1.2、18 dB 的普通 RMSE 约为 1.99985，绕模 2 后的小误差不能替代真实剩余频偏误差。完整校准/测试误差统计见 [frequency_errors.csv](../reports/cfo/frequency_errors.csv)。

**138 项自动测试通过；98,304 次真实频偏补偿栅格检查通过。** 完整计分链路还检查了 81,920 次 Oracle 解调输出与零频偏参考一致，以及各段更新时刻一致。检查数包含 ε=0 的自检。保留测试的 64 段场景链路共 20,480 个计分帧，每分支场景计分数据共 19,660,800 比特；两个场景共享潜在发送比特，32 个不同种子/SNR 分支对应的不同发送计分数据为 9,830,400 比特。四个频偏和三个接收分支不能再乘成新的独立发送数据。
