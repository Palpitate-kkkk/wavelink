# 未知恒定采样时钟偏差：训练标记估计

接收机已知训练序列及其在发射时间轴上的计划位置，但不知道采样率比或初始偏移。它在每个计划位置附近做归一化互相关，用峰值两侧做抛物线插值，然后拟合「观测位置 − 计划位置 = 初始偏移 + 斜率 × 计划位置」。正斜率表示接收采样率高于标称值，斜率乘一百万得到 ppm。低相关峰与搜索边界峰不参与拟合；有效标记不足三个则拒绝输出。

复现：在项目环境中运行 `python -m experiments.clock_estimation_demo`。原始结果见[逐次记录](../reports/clock_estimation/runs.json)。每档噪声覆盖 −200、−100、0、100、200 ppm，各四个种子；每条记录九个计划标记，其中一个缺失，初始偏移五点。训练平均功率作为 SNR 参考，不按整条含空白的录制计算。搜索半径 32 点，相关门限 0.7。

| 训练 SNR | 输出次数 | 成功输出中的最大绝对误差 |
| --- | ---: | ---: |
| 20 dB | 20/20 | 0.301 ppm |
| 5 dB | 20/20 | 1.673 ppm（向上取整） |
| −8 dB | 0/20 | 无估计 |

这是独立的离线估计实验，尚未串接重采样和 OFDM 解调。窗口依赖训练位置先验；搜索半径外的漂移、多径假峰、残余频偏和时变时钟未验证。普通最小二乘不抵抗通过门限的错误峰，残差也不能充当可靠的置信区间。下一步应在有多径和频偏的独立夹具上比较未校正、估计率校正、真值率校正三条路径，分别记录拒绝、擦除和误码。
