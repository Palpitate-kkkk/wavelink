# 回退质量门限：项目收尾验证

仅在时钟估计拒绝时检查回退候选。对九个标称训练窗口分别计算归一化相关幅度，取中位数（缺失标记也占一个窗口）。不搜索峰、不读取载荷答案或真实 ppm。此质量指标与不校正解调共享已知 CFO 去旋转；解调仍用已知信道响应及固定窗口。整条录制一起放行，属于离线策略。

复用[闭环信道](clock_link.md)的四档训练 SNR（5、0、−4、−8 dB）和三档偏差（−200、0、200 ppm）。用 72 条开发录制（810101–810106）遍历 0 至 1、间隔 0.05 的门限及永不回退基线；在开发集新增输出的汇总 BER 不超过 30% 的条件下最大化放行比特，同分选更严格门限。选出 0.30 后冻结，在 96 条独立种子录制（910101–910108）上验证。30% 是实验筛选预算，不是通信系统的交付标准。

| 估计拒绝后的策略 | 新增输出条数 | 减少擦除位数 | 新增误码 | 新增输出 BER |
| --- | ---: | ---: | ---: | ---: |
| 保持拒绝 | 0 | 0 | 0 | — |
| 无条件回退 | 70 | 1,159,200 | 487,199 | 42.03% |
| 相关门限 0.30 | 21 | 347,760 | 96,814 | 27.84% |

21 条放行录制均为 0 ppm；两个 ±200 ppm 档均无放行。门限改善了回退输出的汇总质量，但仍有大量误码，不能当作可靠接收，也不能把汇总 BER 当作逐帧保证。保留拒绝为默认策略；该门限仅作为消融对照。未验证真实 SDR、联合 CFO / 信道估计或编码与 CRC 保护。

复现：`python -m experiments.clock_fallback_gate`。见[开发与测试逐条记录](../reports/clock_fallback_gate/runs.json)。
