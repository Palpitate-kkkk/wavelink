# 采样时钟估计与 OFDM 校正闭环

用独立种子 620101–620104，在 −200、0、+200 ppm 和三档噪声下生成 36 条合成录制。每条有九段 QPSK-OFDM 载荷，其中一段缺训练标记但保留载荷。固定三抽头信道的时延为 0、2、5 点；载波频偏为 0.12 个子载波间隔（按观测采样率定义）。SNR 以发端训练标记的单位平均功率为参考。

估计器直接读取含频偏的录制和计划训练位置。三条解调路径共享**已知 CFO 去旋转、已知信道响应和标称载荷窗口**，仅改变采样率校正。估计值取倒数并近似成分母不超过 100000 的有理数，实际使用的比值逐行保存。估计拒绝时整条录制记为擦除，不自动回退。零偏差行也计入汇总；此时真值路径直接复制，估计路径可能因微小非零估计而滤波。

| SNR | 不校正错误 / 擦除 | 估计值校正错误 / 擦除 | 真值校正错误 / 擦除 |
| --- | ---: | ---: | ---: |
| 20 dB | 62292 / 0 | 0 / 0 | 0 / 0 |
| 5 dB | 67952 / 0 | 15431 / 0 | 14973 / 0 |
| −8 dB | 89355 / 0 | 0 / 198720 | 71902 / 0 |

每个单元格均发送 198720 位。低 SNR 的零错误来自无输出，不能算作零 BER。不校正路径的固定窗口会随时钟误差偏离，故对照仅衡量这个固定窗口协议下的收益，未比较独立定时跟踪器。真值路径给出同一校正框架的参考，不保证是最优接收。该实验仍为离线仿真，未验证联合 CFO/信道估计、实时或硬件接收。
