# 导频子空间告警与正则化回退

本阶段针对上一轮已发现的 L=13 支撑失配，加入只依赖接收导频的启发式告警。旧阈值 0.75 与接收机源码不变，新接收机位于 `src/wavelink/guard.py`；实验通过可选工厂复用原链路，默认调用仍与旧实现逐元素一致。此次是对已知失败结构的修复与独立种子复测，不声称未见场景泛化。

## 告警和时序

16 个导频、原模型长度 13。对原导频 DFT 矩阵 Fp 做完整 QR，取其正交补 Q（16×3）。每帧 T=20 个符号，导频商 z=Yp/Xp 的符号平均记作 zbar；用不重叠符号对估计噪声 Nhat。近 16 帧的分数为：

```
score = sum_frames ||Qᴴ zbar||² / max(sum_frames (3 Nhat / T), 1e-12)
```

帧内静态、模型支撑正确时，信道项被 Q 消去，分数在噪声背景下应接近 1；分母也由观测估计，因此这不是已校准的显著性检验。每 8 帧检查，超过开发阶段选出的阈值才告警。校准帧填充初始监测窗，但只在计分后的在线检查点判决。

`estimate → 当前帧计分 → advance`。当前帧仍由此前确定的矩阵估计；告警后从下一帧切换，不使用当前误码率、真实 PDP、真实时延、真实噪声或隐藏变化时刻。原始统计触发器在告警前继续运行，告警后停止。

## 回退先验与代价

回退使用延迟 0..16 共 17 个抽头的均匀 PDP，总平均功率固定为 1；LMMSE 正则化噪声来自近期导频差分估计。此后每 32 帧更新噪声，均匀 PDP 保持不变。总功率为 1 是明确配置的总体先验，不是已估出的真实路径结构，也没有逐帧把信道能量归一化。

CP=16 能覆盖最大整数时延 16，但 16 个导频不能唯一恢复任意 17 抽头信道。回退靠先验正则化获得有限估计，并不消除不可辨识性。该栅格的 L=16 最小二乘条件数约 319.39、噪声增益约 1676.26；L=13 分别约 14.35、33.89。直接扩展无正则化 LS 可能付出严重噪声代价，不能只追求覆盖更长时延。

本版本告警会锁定到整段结束，没有自动退回 L=13。加入 `return15` 场景专门衡量越界路径消失后的精度代价。减少状态切换并不保证误差更小，也不代表已经解决重复失配与恢复问题。

## 开发与保留测试

配置：[guard.json](../experiments/guard.json)。开发 8 个新种子 121001..121008，保留测试 32 个新种子 131001..131032；均与此前开发、测试和泛化审计种子隔离。每段初始校准 64 帧，测试 320 帧，每帧 20 个计分符号；变化发生在 64..95，测试种子随机覆盖全部 32 种相位。每种配置两个初始 Eb/N0（6、18 dB）。

七个场景：统计不变、仅噪声×4、上界内新路径、延迟 13/15/16 越界路径、延迟 15 出现 64 帧后恢复初始统计。所有计分信道均用等长 17 抽头数组，便于复用潜在随机样本。越界时延的平均功率为 0.7，延迟 0/4 分别为 0.1/0.2。早期、晚期窗口各 64 帧，post_all 为变化后的 224 帧；return15 的该窗口包含恢复后的 160 帧。

候选阈值预设为 2、4。开发选择要求：所有支撑正确的场景中告警链路数为零，post_all 各单元平均 NMSE 不超过原触发器的 1.05 倍，所有越界场景不超过其 0.5 倍；选最小合格阈值。若没有候选合格，明确记录失败并选择最大阈值，仍保存全部结果。开发标签可用于选型，但接收机运行时不能访问它们。

`selection.json` 在测试开始前落盘，包含选择规则、候选结果、配置/源码/开发结果哈希与 UTC 时间。测试完成核验锁和源码未变。种子和参数不按测试结果重选。这是经验开发规则，有限样本没有告警不等于误报概率为零。

## 结果

开发阶段两个候选均未通过全部门槛：支撑正确场景未告警，但 `return15` 在 6 dB 的 NMSE 比最坏为 1.06107，超过预设 0.5 条件。按预先定义的失败兜底规则锁定阈值 **4**；`eligible_candidate_found=false` 保留在选择记录中，不能称为开发条件全部通过。独立测试也未消除该缺陷，未重新调参。

stationary / noise_jump / new_paths 共 192 个测试场景链路未告警，输出与原触发器完全一致。这些场景复用 64 个独立种子/SNR 流，不能把 192 当成独立重复数。四个含越界状态的场景共 256 个场景链路全部在变化之后告警，首次生效延迟为 1..10 帧，没有变化前告警；这是本配置下的观察值，不是任意场景的检出保证。

**恢复后的代价保留：** return15 的 6 dB post_all 中，BER 从 0.196584 升至 0.213851，NMSE 从 0.356355 升至 0.392522。该阶段的设计目标没有全部达成；先验过宽和不解除锁定的代价需要作为下一版研究问题。

**验证：75 项自动测试，392/392 非 Oracle 条件 NMSE 残差检查、56/56 Oracle BER 检查通过。** 测试集为 448 个场景链路、143,360 个计分帧、206,438,400 个场景计分数据比特；因七场景共享潜在流，不能称为同等数量的独立发送比特，64 个流对应的独立随机发送数据为 29,491,200 比特。测试检查通过只说明实现与评测模型相容，不改变开发精度门槛失败的结论。

## 检查、成本和限制

自动测试覆盖残差正交性、噪声归一化、估计/更新因果顺序、观测复制、未来输入不影响过去结果、告警锁定、17 抽头正则化、无告警时与旧触发器逐元素一致，以及可选工厂保持旧链路结果不变。

条件 NMSE 的预测在当前帧计分前，使用当时矩阵与评测真值计算；这些真值只用于评分。SE 以独立整段链路为单位，未将相邻帧、重叠窗口或多个场景当成独立重复。各场景复用潜在随机流，应使用同场景配对结果，不能把场景计数相加当作独立样本数。误差残差的 6 SE 检查只用于发现实现/尺度错误，不是算法精度保证或正式多重检验结论。

`updates` 统计对下一帧生效的模型替换次数；若同一帧原策略先重建又被回退覆盖，只计一次有效替换，计时仍包含两次计算。`feature_frames` / `monitor_checks` 汇总原触发器及告警器工作，可能对同一观测计数两次；初始化特征计入帧数，但其耗时在 `initial_fit_ms`。`history_complex_values` 仅为原始导频历史缓冲大小，不是整个对象的内存占用。计时为诊断，不主张总体加速。

残差异常也可能来自频偏、帧内时变或其他建模误差，不能唯一诊断为新时延。单元测试构造了 17 抽头导频矩阵的非零零空间向量：导频完全看不见，而数据子载波响应非零，说明告警不可能认证所有 CP 范围内信道。当前实验只覆盖独立零均值不相关抽头、理想同步、整数时延、足够 CP、无编码 SISO QPSK 仿真，没有硬件测量，也未验证分数时延、相关抽头或多普勒。

下一步可在新开发流上研究解除锁定和模型选择，并引入不同导频密度/长度先验；需要同时看误告警、漏告警、返回正常后的代价与真实链路误码率。
