# 导频创新残差触发与弱路径适应

上一阶段发现，28 导频的完整 L=17 模型虽然可辨识，但部分弱路径无法触发原有 PDP 整体变化规则，初始学到的近零长时延功率会继续压制新路径。本阶段增加协方差残差检查，保留旧触发器、拟合窗口、冷却期和全部旧源码。新类位于 `src/wavelink/innovation.py`，旧算法和旧实验均按上一版 metadata 的源码 SHA-256 核验。

## 模型和触发公式

导频商 z=Yp/Xp 在每帧的 T=20 个符号上取平均，记为 zbar。当前学习得到的抽头功率为 p，Fp 为导频 DFT 设计矩阵，当前模型噪声为 Nmodel。定义：

```
C = Fp diag(p) Fpᴴ
lambda = Nmodel / T
B = lambda (C + lambda I)^(-1)
score = mean_recent ||B zbar||² /
        max(||B Fp diag(sqrt(p))||F² + Nrecent/T ||B||F², 1e-12)
```

用线性求解构造 B，不显式计算矩阵逆。Nrecent 由近期导频符号差分估计。若当前零均值、不相关抽头协方差及噪声假设正确，分母对应该残差能量的模型期望。当前先验几乎不支持的新方向会留下残差；这样可以检查整体 PDP 相对 L1 变化较小时，是否仍有超出模型预期的信号。

这里的 innovation 是正则化导频残差，不是卡尔曼滤波创新，也不是已经白化的卡方统计量。模型由重叠历史样本拟合，噪声也由观测估计，分数不是已校准的显著性检验。只把它作为需要独立验证的启发式更新条件。

原触发条件仍是 `max(|log(Nrecent/Nmodel)|, relative L1 PDP difference) > 0.75`；新增 score 超阈值也可请求重建。两者每 8 帧检查，共用 32 帧冷却期，每次都用相同的最近 64 帧缓存矩统计拟合，不更改抽头功率下界或引入额外导频。若同时满足，只重建一次；日志标记 statistics / innovation / both。

当前帧先使用旧矩阵估计并计分，再累积当前导频、检查并更新，最早用于下一帧。残差检查即使发生在父类更新之后，也使用计分时模型对应的缓存 B；随后才刷新下一次的残差矩阵。运行时没有真实 PDP、路径功率、变化时刻、BER 或真实噪声输入。

## 独立开发与保留测试

固定 28 导频、24 数据子载波、FFT=64、CP=16、L=17，初始校准 64 帧。每段 320 帧，每帧 20 个计分符号，变化相位均衡覆盖 64..95；post_all 为变化后 224 帧，early/late 各 64 帧，pre=32 帧。所有方法使用相同导频和发送/信道/标准噪声样本，沿用上一版独立子流生成器。

固定包括导频/CP 的名义数据 Eb/N0，初始 6、18 dB。两种触发方法、周期方法及回退参考资源完全一致；噪声×4场景的实际 Eb/N0 比初始值低约 6.02 dB。名义能量约定不包括每帧用于 FIR 稳定的一个 warmup 符号；其共同能量因子为 21/20，不改变本轮同栅格方法比较。

开发种子 171001..171008，保留测试 181001..181032，与之前全部开发和测试种子隔离。测试独立覆盖全部 32 种相位；开发随机取 8 个相位。配置：[innovation.json](../experiments/innovation.json)。

场景为 stationary、noise_jump、persistent15、weak15、mild15、return15、return_new、repeat64、repeat24。weak15 的延迟 15 功率为 0.05，延迟 0/4 功率为 0.75/0.20；新增 mild15 的延迟 15 功率仅 0.01，延迟 0/4 功率为 0.79/0.20。其他状态和时间安排沿用上版定义，所有计分 PDP 长度均为 17、总平均功率为 1，不逐帧归一化。

参考包括：原 L17 统计触发器 legacy17；L17 最近 64 帧、每 32 帧重建的 periodic17；原 L13 告警/恢复器 recovery13；真实统计 matched 和瞬时 CSI 的 oracle_zf。后两者获得的真值只作为评分参考，学习方法不获得这些输入。

预设候选补充阈值为 2、4。开发门槛为：每个场景/SNR 的 post_all 平均 NMSE 不超过 legacy17 的 1.05 倍；weak15、18 dB 的该比值不超过 0.75；静态场景平均重建数相对 legacy17 的增加不超过 1。选最小合格阈值；若均失败，选最大阈值并保留失败。

两个候选均通过开发条件，按预设规则锁定 **2**。其最差 post_all NMSE 比为 1.0，weak15、18 dB 比为 0.14332，静态额外平均重建数为 0。阈值 4 在这个弱路径单元的比值为 0.10296，但选择规则不是取单元最优值，因此没有据此重选。`selection.json` 在测试前写入，包含开发结果、规则、配置/源码/开发输出哈希和 UTC 时刻；测试后核验未变，没有测试调参。

## 独立测试结果

18 个场景/SNR 单元的 post_all 平均 NMSE 均不高于 legacy17；这仍是预设测试上的经验均值结果，不是普遍优势保证。

| 场景 | 初始 Eb/N0 | 旧 L17 BER | 新触发 BER | 旧 NMSE | 新 NMSE |
|---|---:|---:|---:|---:|---:|
| weak15 | 6 dB | 0.136815 | 0.131852 | 0.075781 | 0.058927 |
| weak15 | 18 dB | 0.031494 | 0.013849 | 0.043664 | 0.006950 |
| mild15 | 6 dB | 0.127776 | 0.127501 | 0.045895 | 0.045003 |
| mild15 | 18 dB | 0.016011 | 0.012894 | 0.011530 | 0.005064 |
| persistent15 | 6 dB | 0.137939 | 0.133815 | 0.076805 | 0.064163 |
| persistent15 | 18 dB | 0.024784 | 0.017439 | 0.033994 | 0.016785 |
| return_new | 6 dB | 0.157781 | 0.153299 | 0.140335 | 0.130295 |
| return_new | 18 dB | 0.038076 | 0.023860 | 0.067472 | 0.033138 |

weak15、18 dB 的 BER 配对差为 -0.017645 ± 0.001288（1 episode SE）；NMSE 从 0.043664 降至 0.006950。旧方法 32 段链路中有 23 段整段未重建，新方法全部出现变化后有效重建，首次生效为 1..9 帧、平均 4.75 帧。旧方法仅 9 段有对应重建，不能直接把这 9 段的平均延迟当成全部链路平均。

stationary 和 noise_jump 的 BER/NMSE 输出与 legacy17 完全一致。静态场景的旧/新平均重建数也相同：6 dB 为 0.40625，18 dB 为 0.0625；这些背景更新并非零误触发概率的证明。weak15、18 dB 的平均重建数从旧版 0.28125 增至 1.25；周期方法固定 9 次。

**没有全面胜过其他参考。** weak15、6 dB 的 periodic17 BER 为 0.127446，仍低于新方法 0.131852；mild15、6 dB 只从 0.127776 小幅降至 0.127501。return_new、18 dB 的原 recovery13 BER 为 0.020519，也低于新方法 0.023860。真实统计参考和全部其他场景均保留。

**105 项自动测试、360/360 非 Oracle NMSE 残差检查及 72/72 Oracle BER 检查通过。** 保留测试共 576 个场景链路、184,320 个计分帧、176,947,200 个场景计分数据比特；9 场景共享潜在流，64 个独立种子/SNR 分支对应的不同发送计分数据为 19,660,800 比特，不能把场景计分总数称为独立发送数据。

## 响应、统计与开销的含义

`responses.csv` 是每个预设对齐点之后、且在下一次变化前实际生效的第一次模型重建时间，不是已校准的检出时延；静态场景也保留对齐参照。发生背景更新或不同机制同时触发时，需要结合事件原因理解。每个变化区间独立计数，不借用上一状态的更新。

NMSE 是数据子载波总体期望 MSE 除以总体期望信号功率；此处真实 PDP 总功率为 1，因此经验数据 MSE 对应它的样本估计，不是逐帧瞬时归一化 NMSE。条件理论预测使用计分前的模型矩阵和评测统计；真值不输入接收机。Oracle BER 与瞬时真实响应下的条件理论比较。6 SE 残差检查用于发现实现/归一化问题，不是算法精度保证。

SE 以整段独立种子/SNR 链路为单位；保存相对三个实际共享样本参考的配对 BER/NMSE 差及 SE。场景之间共享潜在随机流，窗口也有重叠，不能把帧数、场景数或检查数当成独立样本数；均值门槛通过不代表总体统计非劣效或所有链路均改善。

新增缓存为最近 16 帧的导频均值，并在重建时计算 28×28 残差矩阵。`innovation_cached_complex_values` 只统计导频均值缓存的 448 个复数，不含残差矩阵，也不是总内存。`feature_frames` 汇总原矩特征和导频均值处理，可对同一观测计数两次；初始化额外工作计入 initial_fit_ms，在线特征/检查/残差矩阵求解分别计入 feature_ms / monitor_ms / total_update_ms。没有隐藏额外矩阵求解，也不以更新次数减少推导总体运行时加速。

自动测试覆盖残差协方差代数、模型噪声归一化和新路径敏感性、禁用新触发时与旧版逐元素一致、共享冷却及单次重建、缓存复制与大小界限、未来输入不改变过去结果、先计分后更新、参数/种子隔离、开发规则失败兜底及整段评测输出类型。

## 局限与下一步

本轮直接修改的是触发条件，仍保留 64 帧混合拟合窗口及近零功率先验。新增路径被发现之后，功率估计可能仍受旧状态样本影响；更弱变化、低信噪比和快速切换下的收益有限。不能由一次首次重建认定统计已经收敛，也不声称始终优于周期更新或回退方案。

方法仍假设理想同步、帧内静态、帧间独立、零均值不相关抽头、整数时延及足够 CP；没有验证分数时延、连续多普勒、相关抽头、编码链路或硬件采集。后续可用新开发/保留数据研究触发后的短时再次拟合或功率先验保底，并与周期策略作等价增量实现和正式耗时比较。
