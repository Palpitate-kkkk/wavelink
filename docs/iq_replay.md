# 固定时隙 I/Q 文件回放（v0.24）

本阶段把已验证的突发接收链路接到文件输入，形成可实际运行的离线演示。输入是明确格式的复基带采样与已知导频；接收机不读取发送数据、真实起点、真实 CFO 或信道抽头。验证使用仿真生成文件，尚无真实 SDR 录制数据，也不支持任意连续流检测。

## 文件格式：wavelink-iq-v1

录制目录包含四个文件：

| 文件 | 格式与含义 |
| --- | --- |
| `metadata.json` | 下列六个字段，禁止混入评分真值 |
| `samples.npy` | complex64 / complex128，形状 `(n_slots,1984)`；每行一个完整有限时隙 |
| `pilots.npy` | 复数，形状 `(n_slots,20,28)`，已知数字导频；幅度与 1 的误差不超过 1e-12 |
| `available.npy` | Boolean，形状 `(n_slots,)`；False 表示该时隙输入缺失 |

```json
{
  "format": "wavelink-iq-v1",
  "sample_rate_hz": 1000000,
  "n_slots": 96,
  "slot_samples": 1984,
  "n_fft": 64,
  "cp_len": 16
}
```

数组使用标准 `.npy`，不允许 pickle。缺失行也需有有限采样和合法导频，可将采样置零；可用但全零的行会交给捕获器拒收，和显式缺失区分。输入使用只读内存映射，逐时隙校验后处理；输出判决和逐帧记录仍随总时隙数占用内存，不宣称无限流或实时处理。

发射端必须遵循现有训练头与资源栅格：224 点训练头、21×80 点有效载荷（首个 OFDM 符号预热，随后 20 个计分），原时隙内搜索起点 0…63。采样率用于把归一化 CFO 换算成 Hz，**不执行重采样**。未知原始 SDR 文件需要先正确下变频、重采样、转换格式和提供时隙边界；本模块没有自动完成这些步骤。

已知导频是协议输入，不能用真实瞬时信道或未知数据符号代替。建议保存发射端数字导频为 complex128；量化后的 complex64 QPSK 常不满足此处的严格单位模约定，不能直接当作未经量化的已知导频。

## 运行演示

在仓库根目录、安装项目后执行。首次命令的目标目录必须不存在：

```bash
python -m experiments.iq_file_demo --output results/iq_demo_001
```

它生成 `recording/`，完成文件回放并与原内存路径逐位比较，在 `decoded/` 保存结果。再次执行请换一个新目录，以保留之前的证据。只做一次临时集成检查可运行 `python -m experiments.iq_file_demo`，结束时清理临时文件；`make check` 已包含这一检查。

接收机也可以单独运行，不调用生成器或评分器：

```bash
python -m wavelink.iq_replay run \
  --recording results/iq_demo_001/recording \
  --output results/iq_receive_001
python -m wavelink.iq_replay verify \
  --recording results/iq_demo_001/recording \
  --output results/iq_receive_001
```

`run` 拒绝覆盖已有产物。`verify` 检查显式输入、当前实现和固定输出文件的 SHA-256；它是此文件接口专用入口，不能用通用 `wavelink.audit` 替代。清单一致不是签名或物理真实性证明，也不证明载荷正确。

## 输出与评分边界

| 产物 | 含义 |
| --- | --- |
| `frames.csv` | decoded / rejected / missing，估计起点、归一化 CFO 与 Hz、捕获分数、参考移动、摄入与更新状态 |
| `bits.npy` | int8，形状 `(n_slots,960)`；0/1 为硬判决，−1 为缺失 / 拒收擦除 |
| `events.json` | 因果统计学习的启动及更新事件 |
| `summary.json` | 提供 / 输出判决 / 擦除比特数及启动时隙，不含真实 BER |
| `metadata.json` | 输入、实现及产物哈希，运行环境与固定参数 |

这里的 `decoded` 仅表示输出了硬判决，没有 CRC、编码或已知载荷验证，不等于正确接收。超范围 CFO 被错误接受时也必须输出并记录，不能用真值把它事后删掉。

实现继承捕获门限 0.2、统计门限 0.25、标记阈值倍数 8，物理 FFT 窗口保持原捕获结果；只对统计参考作相位变换。缺失 / 拒收只推进物理时钟，末时隙不摄入、不做无用拟合。输入和实现哈希在处理前后核对，变化时拒绝保存该次结果。

## 已执行的集成验证

固定 96 个合成时隙：前 64 个用于启动观察，其后包含 4 个显式缺失、1 个可用但全零的拒收、8 个超范围 CFO=5.2 的时隙及后续统计变化。仿真真值仅保留在实验评分器内存中，四个录制文件不包含真值。

- 91 个时隙输出硬判决，1 个拒收，4 个缺失。
- 共提供 92,160 bit，其中输出判决 87,360 bit、擦除 4,800 bit。
- 文件路径与冻结内存栅格路径的判决 **0 位差异**，更新事件完全相等；统计在时隙 63 之后启动，末时隙没有被统计摄入。
- 评分器记录输出判决中有 **5,421 个错误比特**。这反映该压力夹具并非可靠接收演示；特别是支持范围外 CFO 仍会错误接受。

这些数量包含初始启动阶段，只用于文件接口与内存路径的一致性验证。它们不是新的独立 BER 研究，不能与旧实验的 320 计分时隙或“20.5% 改善”混合比较。

本机新增 6 项测试，总计 **203 项**通过。新增覆盖：无噪声正确判决、拒收与缺失区分、完整启动和因果事件一致、输入不被修改、complex64 采样、格式 / 非有限值 / 非单位导频拒绝、未知真值字段拒绝，以及输入和输出篡改检测。
