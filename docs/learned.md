# 从导频学习噪声与 PDP：独立校准和测试

本阶段将上一阶段直接提供给 LMMSE 的噪声功率与功率时延谱（PDP）替换为导频观测估计值。采用简单的差分/矩估计基线，观察校准样本预算如何影响测试结果。未引入神经网络，不宣称新估计理论或部署性能。

## 信号模型及保留的先验

沿用 [LMMSE 阶段](lmmse.md) 的 64 点 SISO QPSK OFDM、CP=16、导频间隔 2/4、两种单位总体平均功率 PDP、Eb/N0=0/6/12/18 dB。每帧独立生成不相关零均值复高斯抽头，帧内固定；不做逐帧信道功率归一化。每帧 21 个 OFDM 符号，第一个预热，20 个用于校准观测或测试计分。

接收机知道 OFDM 栅格、单位模导频、帧内信道不变、零均值不相关抽头模型及连续时延上界 `L=13`。它需要在同一传播统计和噪声水平下获得多个独立校准帧。PDP/噪声功率的具体数值不传入 `learn_pilot_statistics()`。

因此本阶段减少了统计先验，仍然保留了时延上界与平稳块衰落假设；不是无先验接收机。校准用到帧内重复观测，但测试估计依然逐符号进行，不对测试符号做时间平均。

## 两个估计量

将已知导频相除得到 `z[f,t]=Yp[f,t]/Xp[f,t]=Fp h[f]+n[f,t]`。函数输入只包含这些复数观测，形状为 `(独立帧, 帧内符号, 导频数)`，另带栅格和 L。

**噪声估计。** 同帧相邻且不重叠的符号对中，信道项相消：

\[
\widehat N_0=\frac{1}{2FKN_p}\sum_{f=1}^F\sum_{q=0}^{K-1}
\|z_{f,2q+1}-z_{f,2q}\|^2,\qquad K=\lfloor T/2\rfloor.
\]

因为单位导频相除保留白噪声方差，差分噪声方差为 2N0。此估计不需要真实信道或真实 N0；若帧内信道变化，差分也包含信号变化，会高估噪声。

**PDP 估计。** 先平均帧内导频，再用部分 DFT 设计矩阵做抽头 LS：

\[
B=F_p^\dagger,\quad \widetilde h_f=B\bar z_f,\quad
\widehat p_l^{raw}=\frac1F\sum_f|\widetilde h_{f,l}|^2
-\frac{\widehat N_0}{T}(BB^H)_{ll}.
\]

第二项扣除 LS 噪声功率。将每个功率和噪声方差限制为至少 `1e-12`，保证 LMMSE 数值有效；不归一化到真实总功率，不从真实稀疏位置挑选抽头，不按测试误差选阈值。`pdp.csv` 保留截断前后功率，`calibration.csv` 保留负功率个数和估计总功率。有限样本时，非负截断会在零功率抽头处引入正偏差。

之后固定模型 `TapDomainLMMSE(layout, estimated_powers, estimated_noise)`，进入独立测试。接口验证样本形状、有限性、至少两帧/两个符号，以及时域 LS 的可辨识性；时延支撑外存在路径或矩阵严重病态时，该估计公式不再保证正确。

## 数据隔离、公平比较和开销

每个物理配置使用三个独立种子。随机数流由 `SeedSequence([seed, channel_index, spacing, snr_index, role])` 指定，role=1 校准、role=2 测试。分别抽取独立信道、导频、数据和噪声。测试帧不参与统计学习、数值阈值选择或预算选择。

4/16/64 帧校准使用同一校准流的嵌套前缀，便于控制样本差异；各预算相关，不能当成独立重复。每个独立种子中，所有方法共享同一批 120 个测试帧。最大预算训练 64 帧，另测 120 帧；较小预算只读对应前缀。每种校准预算都预先固定并单独报告，没有按测试数据选择最优者。

| 接收机 | 具体信息来源 |
|---|---|
| Oracle CSI | 真实瞬时数据子载波响应，仅作参考 |
| Linear LS / Tap LS | 导频；Tap LS 另知 L=13 |
| LMMSE matched | 真实总体 PDP 与真实噪声方差，理想统计参考 |
| LMMSE uniform | 均匀 PDP、真实噪声方差，部分理想先验参考 |
| learned_4/16/64 | 对应独立校准帧估计的 PDP 和噪声方差 |
| learned_noise_true_pdp | 64 帧学习的噪声 + 真实 PDP，仅用于消融 |
| learned_pdp_true_noise | 64 帧学习的 PDP + 真实噪声，仅用于消融 |

后两项不能称为完全从观测学习的接收机。校准帧会占用时间和导频：4/16/64 帧分别为 84/336/1344 个发送 OFDM 符号（包括预热），其中 80/320/1280 个符号用于校准。测试计分量排除校准数据，因此本报告没有将 BER 改善解释为有效吞吐率改善；实际复用周期取决于信道统计保持稳定多久。

## 指标与不确定性

沿用 ensemble NMSE：`E||Hhat-H||² / E||H||²`；真实总体平均功率为 1，因此按帧平均误差即可。它不等于逐帧瞬时归一化 NMSE。

对每次固定的校准结果，使用上一阶段的 `ensemble_nmse(A, true_pdp, true_noise)` 预测其独立测试误差。真值只用于仿真生成和评价，未进入 learned 模型拟合。汇总预测是三个独立拟合模型的理论误差平均。

`runs.csv` 给出每次“校准→测试”重复中的帧级 SE、同帧相对 matched 的配对误差差值及 SE。`summary.csv` 同时给出：

- `conditional_test_nmse_se`：给定三个已拟合模型后的测试抽样 SE，等预算下为各重复 SE 平方和的平方根除以 3。
- `replicate_nmse_se`：三个独立“校准→测试”均值之间的 SE，混合了校准波动和有限测试波动。只有 3 个重复，估计较不稳定，不能用于广泛泛化结论。
- `conditional_paired_nmse_se` 和 `replicate_paired_nmse_se`：相对 matched 的同帧误差差值的对应两种 SE。

理论回归使用给定模型后的条件测试 SE，固定容差为 `|观测-预测| <= 6 SE + 1e-10`。这是模型一致性检查，未作多重比较显著性校正，不等于样本预算效果的显著性检验。Oracle BER 检查对每个重复的帧级“实测 BER 减条件理论 BER”做同样的六 SE 检查。

## 本次保存的结果

2 个 PDP × 2 种导频间隔 × 4 个信噪比 × 3 个独立校准/测试重复；10 种接收机，共 480 行逐重复结果、160 个汇总点。最大校准池共 3072 个独立帧，各小预算复用其前缀；独立测试共 5760 帧、6,912,000 个不同的计分数据比特。接收机共享测试数据，不重复计入比特总量。

在稀疏 PDP、18 dB、导频间隔 4 下，各方法测试 518,400 比特：

| 方法 | 错误数 | BER | ensemble NMSE |
|---|---:|---:|---:|
| Oracle CSI | 3685 | 0.007108 | 0 |
| Linear LS | 43248 | 0.083426 | 0.176411 |
| Tap LS | 6851 | 0.013216 | 0.013394 |
| LMMSE matched | 4396 | 0.008480 | 0.002836 |
| LMMSE uniform + true noise | 6577 | 0.012687 | 0.012149 |
| learned, 4 帧 | 4447 | 0.008578 | 0.003042 |
| learned, 16 帧 | 4412 | 0.008511 | 0.002894 |
| learned, 64 帧 | 4405 | 0.008497 | 0.002859 |

64 帧的 NMSE 在该配置接近 matched 基线；BER 的微小差别未进行配对显著性分析，不宣称 learned 优于或统计等价于 matched。与上一阶段的数值变化也包含新种子造成的抽样差异，应只比较本阶段共享数据的方法。

小样本影响在低信噪比更明显：指数 PDP、0 dB、间隔 4 下，matched NMSE 为 0.314506，4/16/64 帧 learned 分别为 0.359453/0.325119/0.317667。只有 4 帧时，学习到的 PDP 尚有明显波动。本次全配置校准诊断如下，PDP L1 为未按总功率重新归一化的绝对误差：

| 校准帧预算 | 噪声估计/真实噪声的最小–最大值 | 平均 PDP L1 误差 |
|---|---:|---:|
| 4 | 0.9305–1.0765 | 0.4491 |
| 16 | 0.9553–1.0494 | 0.2053 |
| 64 | 0.9792–1.0232 | 0.1013 |

这些是本次 48 次独立校准配置的描述性结果，不是置信区间，也不保证每次增加预算都会改善指标。部分理想先验消融的具体数值保留在汇总表中。

144/144 非 Oracle 汇总 NMSE 理论检查、48/48 逐重复 Oracle BER 检查通过，逐重复估计器 NMSE 检查也全部通过。39 项自动测试通过，新增测试包括噪声扣除、非单位真实总功率、噪声差分的时变反例、嵌套前缀、训练/测试随机流隔离及小规模完整复现。

metadata 的 base_commit 为生成结果前的父提交，dirty 标记表示生成时尚未提交，用源码哈希确定实际运行代码。方法依赖帧内静态、校准/测试同分布、足够 CP、整数时延与正确 L 上界。目前没有覆盖校准之后 PDP/噪声发生漂移、分数延迟、频偏、连续多普勒或硬件接收。单元测试已展示：没有噪声但信道在配对符号之间变化时，也会被差分法误认为噪声。下一阶段应在校准分布改变时评测冻结模型失效，并与有明确开销的更新策略比较。

复杂度：校准需预计算部分 DFT 的伪逆，约 O(Np L²)；帧平均后抽头拟合约 O(F L Np)，噪声差分与导频平均约 O(F T Np)。尚未测时，不能据此宣称实时或低延迟优势。

## 方法参考

[MathWorks 的 Channel Estimation 文档](https://www.mathworks.com/help/lte/ug/channel-estimation.html)讨论用导频估计差值构造噪声水平。本项目在明确的帧内静态模型下采用上述不重叠差分公式，未声称复现 LTE 实现。LMMSE 的二阶统计背景参见 [NXP AN3059](https://www.nxp.com/docs/en/application-note/AN3059.pdf)。当前校准估计量为本项目自行实现的矩估计基线。
