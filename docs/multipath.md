# 静态多径、导频 LS 与 ZF 均衡

## 范围与信号链

数据比特 → QPSK → 资源栅格（数据/已知导频/DC/保护载波）→ 酉 IFFT → CP → 因果线性多径卷积 → AWGN → 去 CP/FFT → 导频 LS 与插值 → ZF → 数据比特。

保持理想定时和载波同步。采用两个明确的固定信道剖面，没有模拟随机衰落总体、运动、多普勒、RF 非线性或全波电磁场；也不是完整 Wi-Fi/5G 标准实现。

## 资源与能量

N=64，采样率为 1 MHz，因此采样间隔 1 µs、子载波间隔 15.625 kHz。激活的有符号频率编号为 -26…-1 与 1…26，数组存储为原生 NumPy FFT 顺序。DC 和其余 11 个边缘子载波置零。

| 名义导频间隔 | 导频数 | 数据载波数 | CP=16 时每时域样本承载数据比特 |
|---|---:|---:|---:|
| 2 | 28 | 24 | 0.6 |
| 4 | 16 | 36 | 0.9 |

每个连续激活频段两端强制放置导频，所以边界处实际间隔可能短于名义值。每符号的导频为独立、零均值、单位能量的已知 QPSK，不做功率提升。接收机获取导频值，不获取未知数据或真实信道。该设定使期望 CP 能量可按长度比例计算。

所有曲线横轴均为**包含导频和期望 CP 开销的发射端每数据比特 Eb/N0**。令 Na=52、Nd=数据载波数：

- E[时域样本功率]=Na/N。
- Eb=Na/(2Nd) × (N+CP)/N。
- 复噪声方差 N0=Eb/10^(EbN0_dB/10)；实虚两维各为 N0/2。
- 样本 SNR=(Na/N)/N0；每激活载波 Es/N0=1/N0。

不能直接复用上阶段全数据载波的 Eb/N0 换算。改变导频数或 CP 会同时改变开销与噪声方差，所以图中跨配置对比是能效/估计质量的联合比较，不是固定 N0 的纯估计器对比。数据载波位置也会随导频间隔改变，因此不足以证明某个密度全局最优。

## 信道和接收机

配置见 `experiments/multipath.json`。short 时延为 [0,1,3] µs，long 为 [0,4,12] µs，复增益在配置中完整列出。每个剖面只统一归一化一次，使 sum|h[l]|²=1；不按每帧接收功率归一化。CP=16 µs 对两者均足够，CP=2 µs 对两者均不足。

卷积跨符号连续；`apply_multipath` 支持显式输入历史，分块计算与整段卷积一致。每个独立实验帧含一个不计分的预热符号来建立历史，随后计分 20 个符号。预热为仿真边界设置，Eb 定义描述持续传输的稳态效率，不把预热当成实际协议免费开销。

三种接收机共享同一份接收数据：

1. **none**：直接硬判决，展示未补偿信道的影响。
2. **oracle_zf**：已知 H=FFT(h)，Xhat=Y/H。理想先验参考，不是可部署估计器；CP 不足时单抽头对角模型仍不成立，即使真实 H 已知也无法去除所有干扰。
3. **ls_linear_zf**：在导频处 Hhat=Yp/Xp，分别对实部和虚部做频域线性插值，然后 ZF。插值仅在各连续激活频段内进行，不跨 DC/保护带，不外推，不使用真实信道。标准 LS 原理参考 [MathWorks 信道估计说明](https://www.mathworks.com/help/lte/ug/channel-estimation.html)。

|Hhat|²≤1e-12 时均衡器输出零，防止除零；当前硬判决将其映射为 00。该数值保护不是恢复深衰落信息的算法，也不是 MMSE 均衡。

## 评测与统计

固定预算：32 个物理配置 × 3 个种子 × 40 帧。每次计分 20 个 OFDM 符号，共发送计分数据 4,608,000 比特（不重复计入三种接收机）。输出 288 个接收机/种子行、96 个汇总点，每点 120 个独立帧。无提前停止。

BER 仅统计数据；NMSE 仅统计数据子载波，定义为 sum|Hhat-H|²/sum|H|²。oracle 的 NMSE 为零只是因为直接使用真实 H，不表示 CP 不足时系统模型没有误差；none 没有估计器，NMSE 留空。

同一帧内不同数据错误可能因共享导频估计而相关，因此这里不把所有比特当作同分布独立 Bernoulli 样本套用 Wilson 区间。报告独立帧均值的标准误 SE，并保存帧统计量的一阶、二阶和以便复核。SE 条件于当前固定信道，不涵盖信道剖面的总体不确定性；未用三组种子声称广泛无线环境泛化。

零观测错误不等于真实 BER=0；SE=0 也不构成零宽度置信区间。对数图仅将零错误点放在 0.5/总测试比特处以便显示，这不是估计值或置信上界，CSV 保留实际计数。

CP 足够时另用已知信道的解析基线验证：各数据载波 p_k=0.5 erfc(|H_k|/sqrt(2N0))，平均为 oracle BER。16/16 个汇总点通过固定的 |错误数−期望错误数|≤6sqrt(期望错误数)+5 回归容差。这个工程检查不作为严格显著性检验；低错误率点精度仍有限。

## 实际结果与结论

18 dB、long 信道、CP=16、名义导频间隔 4，共 172,800 数据比特：

| 接收机 | 错误数 | BER | 数据载波信道 NMSE |
|---|---:|---:|---:|
| 未均衡 | 28,969 | 0.167645 | 不适用 |
| 理想 CSI + ZF | 9 | 0.00005208 | 0 |
| LS 线性插值 + ZF | 890 | 0.00515046 | 0.196108 |

这表明该场景下 LS 插值仍明显落后于理想信息参考。把名义导频间隔降到 2 后，此点 NMSE 为 0.045901、BER 为 0.001171875，但伴随额外导频开销和不同数据载波位置，不能把它表述为无代价的提升。

无噪声匹配栅格对照进一步定位原因：long、CP=16、spacing=4 的频域循环卷积模型误差约 6.10e-32，而 LS 插值 NMSE 仍为 0.186774。说明 CP 充分并不能消除稀疏采样与插值偏差；spacing=2 时无噪声 NMSE 为 0.034614。

同一 long 信道、同一无噪声发送栅格，CP 从 16 缩为 2 时，spacing=4 的循环卷积模型误差增至 0.031226，验证了 CP 不足造成模型失效。主实验中短 CP 有时得到较低 BER/NMSE，是较小能量开销降低 N0 与干扰共同作用的结果，不能据此否认 CP 不足的物理影响。

这些是指定静态信道下的仿真结论，不是创新算法优越性证明。下一步适合加入 DFT/时域结构约束估计，与现有 LS 对比，并明确它利用的信道长度先验及失配条件。

## 复现

```bash
python -m pip install -e '.[plots]' -c experiments/requirements.txt
python -m unittest discover -s tests -v
python experiments/multipath_ber.py --output results/multipath --plot
```

Python 3.13.5、NumPy 2.4.1、Matplotlib 3.10.8；21 项测试通过，包括资源空载波、平坦信道 LS 精确恢复、频率顺序插值、跨块卷积、CP 边界、导频噪声功率、发射能量换算、除零保护和实验计数/复现。`reports/multipath` 保存参考结果；metadata.json 记录运行代码哈希、配置和基础 commit。默认输出在被忽略的 results 下，避免覆盖参考结果。
