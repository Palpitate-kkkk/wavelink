# 已知采样率的离线校正（v0.26）

本阶段补充采样时间坐标转换及接收集成核对。只补偿**已知且恒定的采样率比值**，不估计未知 Sampling Frequency Offset（SFO，采样频率偏差），不等同于 CFO（载波频偏）校正。

## 接口与数学约定

新增 `wavelink.rate_conversion`，仅依赖 NumPy。输入为非空、有限的一维 complex64 / complex128 `.npy` 流。输出率 / 输入率严格约分为 `up/down`，支持 0.5 至 2 倍、约分后每项不超过一千万；不悄悄近似声明的采样率。

输出第 m 个样本对应输入位置 `m * down / up`，原点为 0，默认长度 `ceil(N * up/down)`。可显式裁掉尾部，不能要求超过自然长度。每段计算使用全局位置，分块不会重置采样时钟。相同采样率直接复制。

插值器为半径 32 的 Hann 窗 sinc 核，完整相位核按直流增益归一化；截止频率为 `0.94 * min(1, up/down) / 2` 周期 / 输入样本。录制外按零延伸，边界不重新归一化。没有按输入 / 输出能量重置幅度，也没有 AGC。低通再改变采样率的一般背景可参阅 [SciPy 官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.resample_poly.html)；这里是自行实现的窗口 sinc 插值，不是调用或复现 SciPy 多相算法。

这是**离线、非因果前端**：最多读取未来 32 个输入样本。1 MHz 时相当于最多 32 μs 前视，未包含计算时间。它会让同步前缀间接使用邻近载荷样本，因而改变旧捕获实验的信息预算；后续接收机继续按因果顺序更新，也不能据此称整个系统因果或实时。

## 可重复运行

```bash
# 生成三种已知采样率的合成观测、未经校正 / 校正接收结果
python -m experiments.clock_audit --output results/clock_new --report results/clock_report
python -m wavelink.audit --report results/clock_report

# 将上述 1.024 MHz 一维观测转换为 1 MHz；明确选择原来的190464点
python -m wavelink.rate_conversion \
  --input results/clock_new/rate1024k/observed.npy \
  --output results/converted_clock \
  --input-rate 1024000 --output-rate 1000000 --output-count 190464
```

输出 `stream.npy` 和 `metadata.json`，记录原始文件、输出文件、实现 SHA-256、时间坐标、尾部裁剪、滤波参数和运行环境。已有目录拒绝覆盖。声明的输入率必须由调用者提供，本工具无法证明它正确。该独立流接口尚未自动接入 SigMF 导入器；SigMF 现有严格采样率限制保留，也不自动生成任意连续流的时隙标记或导频。

## 固定接收对照

[逐项结果](../reports/clock/runs.csv)、[噪声检查](../reports/clock/noise.json)、[来源与协议](../reports/clock/metadata.json)。根种子 361001，复用 v0.24 的 96 个合成时隙，每时隙 1984 点 / 960 个载荷比特。64 个启动时隙也计分，因此不能与旧报告的 320 个测试时隙直接比较。三种情况共享同一数据，不是三个独立统计重复。

生成器采用**带零保护的周期 DFT 频谱扩缩**，与校正器的窗口 sinc 独立实现；这是受控数值模型，不是模拟 ADC 或真实 SDR。生成时钟及校正参数均事先固定，未根据结果选参。

“接收损失”定义为 `(错误比特 + 擦除比特) / 92160`，擦除不被当成正确。

| 声明输入率 | 未校正损失 | 已知率校正损失 | 校正后波形 NMSE |
| --- | ---: | ---: | ---: |
| 1,000,100 Hz（+100 ppm） | 10.6467% | 10.6185% | 0.0105812 |
| 999,900 Hz（−100 ppm） | 18.6209% | 10.6120% | 0.0106032 |
| 1,024,000 Hz | 98.4028% | 11.1155% | 0.0104865 |

这些数字只证明固定夹具能运行并暴露处理代价，不是泛化 BER 增益。未经时钟合成的原始文件有 5421 个错误比特、4800 个擦除比特，损失 11.0905%；校正结果并未逐位还原它。+100 ppm 的损失变化尤其小，不能据此声称普遍提升。

滤波改变满带宽同步标记及边界。原来全零的第 68 时隙，经过时钟合成及校正后可受到邻近样本影响：两个 ±100 ppm 案例中它不再被拒绝。这也说明接收损失变低不代表物理正确性得到证明。该实验未加入传感器掉线模型：四个缺失标记直接继承既有时隙语义，不重新估计连续录制中的缺失位置。

未经校正的 −100 ppm 流只够 95 个完整时隙，末时隙明确计缺失；不把补零尾部作为真实接收数据计分。三种校正均从自然长度明确裁去 1 个尾样本，恢复原声明的时隙总数。所有方法都计入原有的四个缺失时隙。

## 噪声与验证边界

固定白噪声种子 371001，65536 点。输入平均功率 1.00329，128/125 转换后去边缘平均功率 0.92912，按插值系数平方和预测的单位输入噪声方差增益为 0.92725；相邻样本协方差实部约 0.09586。有限样本测量与期望不是严格相等的量。输出噪声已相关，不能重套独立白噪声假设或重新声称相同 Eb/N0。

9 项新增测试覆盖解析复指数的物理时间 / 幅度、超输出 Nyquist 频率的混叠抑制、脉冲原点、直流边缘、全局分块一致性、噪声增益、独立 DFT 的奇偶 / Nyquist 处理、非法输入及输出清单。集成检查验证时隙 / 擦除账目、明确尾部长度和固定夹具的时间重建容差，不要求每个场景都提高 BER。

下一项有价值的验证是：在独立开发 / 测试数据上设计未知时钟偏差估计器，明确前视与导频预算；随后再接实际录制文件。真实硬件、时变时钟、连续多包检测和实时性仍未验证。
