# 范围与验收路线

定位：电磁场与无线技术 / 通信方向的项目实践，用于展示研究与工程能力。

## M0：基础模块（已完成）
- [x] 单位能量 QPSK、酉 FFT/IFFT、循环前缀。
- [x] 无噪声回环与能量检查。
- [x] 确定性多径下的频域模型验证、CP 不足反例。
- [x] 在干净虚拟环境验证安装流程与依赖（AWGN 阶段完成）。

## M1：可信统计基线
- [x] AWGN 生成及经验噪声功率验证。
- [x] QPSK BER 与理论曲线对照；明确样本 SNR、Es/N0、Eb/N0。
- [x] 固定种子配置、错误数与总比特数、置信区间、停止准则。
- [x] 导频和保护子载波配置、LS 估计与均衡。
- [x] 静态多径、CP 边界与导频插值误差评测（见 multipath.md）。

## M2：非理想接收
- [ ] 独立控制多径时延、频偏、定时误差和多普勒。
- [ ] 帧同步、频偏估计与补偿，并逐项消融。
- [ ] 每个信道参数记录单位、归一化及物理适用范围。

## M3：第一条研究主线
- [x] 部分 DFT / 时域约束 LS：长度先验失配、条件数与偏差-方差分析（tapls.md）。
- [ ] 比较 LS、DFT 去噪和 LMMSE，记录各算法可用的先验信息。
- [x] 分别改变噪声功率假设与不相关抽头 PDP，测量统计失配影响（lmmse.md）。
- [x] LS / 时域 LS / LMMSE 在随机块衰落下的共享样本比较与理论 MSE 校验。
- [x] 从独立校准帧的导频估计噪声/PDP，对照理想统计先验，比较样本预算（learned.md）。
- [x] 校准/测试之间的阶跃统计漂移、因果周期/滑窗更新与重建次数（drift.md）。
- [x] 全 32 相位随机分配、16/64 帧缓变统计与配对策略比较（robustness.md）。
- [x] 基于导频观测的更新触发：开发流锁定阈值、独立测试流、误触发/延迟与监测开销（triggered.md）。
- [x] 保持整个接收机冻结，审计未见幅度、时延上界内/外新路径和重复漂移；保留结构性失败（generalization.md）。
- [x] 新版本的时延上界失配告警与正则化回退、独立种子复测；保留开发门槛失败和恢复后退化（guard.md）。
- [x] 滞回解除、最近历史重校准与独立种子复测；量化恢复收益及 72..79 帧等待（recovery.md）。
- [x] 冻结策略下的导频密度/完整时延模型审计，固定 Eb 与固定噪声两种预算、共同子载波配对比较及资源代价（density.md）。
- [x] 协方差创新残差补充触发：开发锁参、独立弱路径测试、共享冷却及额外计算开销（innovation.md）。
- [x] 创新事件后的单次延迟复核：计划取消/替换、开发锁参、独立晚期收益与额外重建/快速变化代价（followup.md）。
- [ ] 功率先验、低 SNR 与更弱变化仍需改进；锁定方法应扩展到真实同步误差审计。
- [ ] 真实同步误差、分数时延和编码链路上的独立验证。
- [ ] 对触发/周期策略做同等增量优化与正式耗时基准，检验低复杂度收益。
- [x] 独立随机重复、BER/NMSE、失败边界及技术报告；正式耗时结论仍待验证。
