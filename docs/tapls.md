# 部分 DFT 时域约束 LS：信道长度先验失配

## 问题与实现边界

上一阶段发现：CP 足够时，稀疏导频加线性插值仍可能有较大误差。本阶段利用有限信道长度这一结构，将估计参数从各个数据子载波的独立响应改为时域连续抽头。

本实现称为 **Tap-domain LS（时域抽头 LS）**，使用部分 DFT 设计矩阵。它不是把线性插值结果直接 IFFT、截断、再 FFT 的另一种常见 DFT 去噪流程，也不是 LMMSE、稀疏估计或新提出的算法。LS 的导频基本原理可参考 [MathWorks 信道估计说明](https://www.mathworks.com/help/lte/ug/channel-estimation.html)；以下明确给出本项目使用的矩阵与推导。

## 数学定义

假设因果整数采样时延支持为 0…L−1。L 是最大时延样本数加一，不是非零路径数量。两个信道各有 3 条非零路径，但真实长度分别为 4 与 13。

对导频索引 k_p 与时域索引 l，F_p[p,l]=exp(−j2πk_p l/N)。对数据索引同样构造 F_d。导频单位模，先做 z_p=Y_p/X_p；此时各导频噪声仍独立、同方差 N0。

- hhat=argmin_h ||F_p h−z_p||² = F_p† z_p。
- Hhat_d=F_d hhat=A z_p，其中 A=F_d F_p†。
- 对数据子载波继续使用上一阶段相同的 ZF 与硬判决。

F 是信道响应的非归一化 DFT 矩阵（H=FFT(h)），不要因为发送链路采用酉 IFFT 就额外除以 sqrt(N)。使用有符号索引和原生 FFT 索引在整数时延上等价。

采用 SVD 构造伪逆，预计算 A，避免显式求逆 F_p^H F_p。约束 L≤导频数，检查有效列秩与条件数；秩亏或条件数>1e8 的配置会拒绝，不能悄悄使用一个不唯一的最小范数解充当已辨识信道。

代码只接受单位模导频。若不同导频功率不等，除导频后噪声异方差，需要加权 LS，当前实现明确拒绝这类输入。DC/保护载波不作为“零信道观测”参与拟合。

## 先验使用与公平比较

L=2、4、8、13 对两个信道都完整扫描，没有根据测试 BER 挑选“最佳 L”作为部署结果，也未实现在线长度估计。L=4 对 short 匹配；L=13 对 long 匹配，但这种匹配是评价场景，接收机实际部署时未必拥有该先验。估计器不使用真实非零路径位置、增益、噪声方差或真实 H。

保持上阶段数据、随机种子、导频、CP/能量定义不变，仅将 CP 固定在 16 点，满足两个信道的长度要求。每次仿真各接收机共享接收样本；两种导频间隔为 2 和 4。跨导频密度对比仍同时改变开销和数据载波位置，只在同配置内解释方法差异。

总计 16 个物理配置×3 种子=48 次链路仿真，传输计分数据 2,304,000 比特；7 种接收机产生 336 个逐次行、112 个汇总点。每个汇总点来自 120 个独立帧。固定帧数停止，报告错误计数、BER、NMSE 和帧级 SE。

## 偏差与方差的独立理论核验

在充分 CP、理想同步、固定信道、单位模导频与 AWGN 条件下：

E||Hhat_d−H_d||² = ||A H_p−H_d||² + N0 ||A||_F²。

除以 ||H_d||² 得到预测 NMSE。第一项为模型先验导致的偏差，第二项为噪声经估计矩阵放大后的方差。真实 H 仅在独立评价函数中用于计算这些理论项，不进入接收机 estimate()。

匹配或覆盖真实支持且满秩时，无噪声偏差接近浮点误差；L 过短时遗漏路径带来非零偏差。L 过长通常增大可拟合的噪声自由度。本次 spacing=4 的总数据噪声放大系数 ||A||_F² 从 L=4 的 8.9154 增至 L=13 的 33.8910；条件数分别为 1.4658 和 14.3472。

64/64 个时域估计汇总点满足固定工程回归容差 |实测 NMSE−预测 NMSE|≤6×帧级 SE+1e-10。16/16 个 oracle BER 检查也通过。这是预设一致性检查，不是经过多重比较校正的严格显著性检验；不根据检查结果调整种子。

## 实际结果

以下均为 18 dB、CP=16、导频间隔 4，每点 172,800 数据比特。

### long：真实长度 13

| 接收机 | 错误数 | BER | NMSE |
|---|---:|---:|---:|
| 线性插值 LS | 890 | 0.00515046 | 0.196108 |
| 时域 LS，L=2 | 3606 | 0.02086806 | 0.223647 |
| 时域 LS，L=4 | 3099 | 0.01793403 | 0.214586 |
| 时域 LS，L=8 | 513 | 0.00296875 | 0.112235 |
| 时域 LS，L=13 | 77 | 0.00044560 | 0.0149585 |
| 理想真实 CSI | 9 | 0.00005208 | 0 |

长度匹配时明显接近理想参考，但仍有估计噪声；过短 L=4 反而比线性插值更差。L=4 的预测 NMSE 中，偏差约 0.210647，噪声方差约 0.003869；提高 SNR 无法去除这项模型偏差。

### short：真实长度 4

| 方法 | NMSE | 观测比特错误数 |
|---|---:|---:|
| 线性插值 LS | 0.00832292 | 0 |
| 时域 LS，L=4 | 0.00341585 | 0 |
| 时域 LS，L=8 | 0.00690036 | 0 |
| 时域 LS，L=13 | 0.0127905 | 3 |

这里过长 L=13 虽然无噪声可精确恢复，但噪声代价使 NMSE 比线性插值还大。因此不能宣称“时域约束总是优于线性插值”或“L 越大越好”。低 SNR 下，偏差与方差权衡甚至可能让过短模型获得较低 NMSE。

零观测错误不表示真实 BER 为零，也不支持在两个零错误方法间宣称 BER 提升。对数图将零错误点暂放在 0.5/比特数处作显示，CSV 保留实际零计数。帧级 SE 条件于两个固定剖面，未给出方法差值的配对置信区间，不据此作总体显著性声明。

## 尚未解决的问题

只覆盖两种固定、整数采样时延信道；未覆盖分数时延、移动多普勒、同步偏差或信道长度在线选择。没有进行实测运行时间对比，也不宣称速度优势。预计算 SVD 大致 O(Np L²)，应用预计算 A 的在线代价为每符号 O(Nd Np)；这一实现为透明验证优先，并未利用 FFT 或矩阵结构加速。

下一步可加入正则化/LMMSE 及噪声统计失配，或用独立验证条件选择 L；需分别说明新增先验与评估边界。
